3. 数据库连接警告反复出现的原因

2026-11-02 已通过当前代码和隔离连接复现。api/apps/__init__.py 的请求 teardown 调用 close_connection；api/db/db_models.py 对 MySQL 执行 DB.close_stale(age=30)。Peewee 的 close_stale 遍历整个池的已借出连接，按 checked_out 时间强制关闭底层连接；它不会同步重置其他线程持有的 Peewee 状态。因此同一连接可能出现 is_closed=False，而 PyMySQL open=False、_sock=None。下次 SQL 在客户端抛出 InterfaceError(0, '')，此时 SQL 尚未发给 MySQL。
