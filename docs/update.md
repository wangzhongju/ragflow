# RAGFlow 更新日志

按日期记录整体原因与更新描述。详细排查和修复过程见 [issue.html](issue.html)，稳定部署操作见 [operations.html](operations.html)。原操作手册没有详细记录的条目不在 issue.html 补写，既有专题文档继续保留。

## 2026-11-04

### 外部 Agent 独立文件解析接口

- **原因**：外部 Agent 需要直接解析文件，供知识使用和训练数据制作，不应为了读取文本先创建知识库。
- **更新**：Python API 新增带 API Key 鉴权的文件解析与能力查询接口，复用现有解析器，提供可分发 Skill。完成本地契约测试与静态检查；尚未部署或进行真实 OCR 集成验收。[详细过程](issue.html#external-file-parse) · [接口使用](file-parsing.md)

### 文档职责整理

- **原因**：部署操作与历史排障混杂，手册持续增长且不便复查。
- **更新**：将现有详细记录按日期和条目迁移至 issue.html；operations.html 保留稳定操作，update.md 精简为原因与更新描述，并修正交叉链接。

### 修复数据制作管道画布加载错误

- **原因**：一次性创建脚本把执行参数覆盖到画布表单，导致 Parser 的 `.map` 异常。
- **更新**：修正该管道的 Parser/TokenChunker 表单和创建脚本，页面保存刷新通过，运行参数与已解析数据保持不变。[详细排查与修复](issue.html#data-factory-pipeline-ui)

### 数据制作二期与开发解析队列隔离

- **原因**：数据制作需要统一多模态标准与独立生成器，开发解析任务还存在跨环境消费。
- **更新**：交付内嵌页面、三类生成器、资产/审核/版本/导出；隔离 91/92 队列并完成八页 PDF 重建。质量有误样本驳回，训练不在范围内。[详细过程](issue.html#data-factory-v2)

## 2026-11-02

### 1. 官方资源缓存与开发/生产镜像拆分

- **原因**：外部资源获取分散，前端开发更新依赖镜像重编译。
- **更新**：统一官方资源缓存与 dev/prod 镜像，开发使用 Vite 热更新，生产使用静态构建；部署与运行资源验证通过，未执行完整 CI/压测。[实施与回退](issue.html#dev-prod-results)

### 2. 聊天图片描述请求长时间等待

- **原因**：聊天等待集中在模型调用阶段；缺少同时间窗口模型日志，不能确定具体排队原因。
- **更新**：完成只读核查和最小探针，确认原请求成功返回；未重启服务或调整配置。[排查证据与复发步骤](issue.html#chat-latency)

### 3. 数据库连接警告反复出现的原因

- **原因**：请求结束时全池关闭借出超过 30 秒的连接，其他线程下次 SQL 触发断连重试。
- **更新**：通过隔离连接复现并定位线程归还问题，本条仅记录原因核查。[详细证据](issue.html#db-connection-warning)

### 4. 修复数据库连接告警

- **原因**：连接清理与健康探针未在持有连接的线程中正确管理连接生命周期。
- **更新**：改为归还当前线程连接，健康检查使用连接上下文；专项测试及两端部署验证通过。[修复、验证与回退](issue.html#db-connection-fix)

### 5. VS Code 连接容器的 Git 标记与红线

- **原因**：VS Code 以 root 附加，而仓库属于 cdky；部分 Pylance 提示涉及动态 ORM 推断及注解。
- **更新**：恢复当前会话 Git 识别，补充普通用户附加配置及诊断方法，未批量修改业务类型。[排查步骤](issue.html#vscode-container)

### 6. 按要求仅通过配置减少 Pylance 类型提示

- **原因**：用户要求通过配置减少类型提示，而不修改业务代码。
- **更新**：仅将 91 个人工作区的 Pylance 类型检查改为 off，保留其他设置并备份；此操作不修复代码缺陷。[操作与恢复](issue.html#vscode-typecheck-off)
