# Build RAGFlow Docker Image

This checkout mounts application source into its runtime container. See the [Docker directory](../../docker/README.md) and [operations manual](../operations.html#mount).

```bash
bash docker/docker.sh build runtime ragflow-local:v0.27.2-runtime
# Full Python dependency and frontend rebuild, after preparing ragflow_deps:
bash docker/docker.sh build source ragflow-local:my-release
```

Set `RAGFLOW_IMAGE` in `docker/env/app.env`, then run `bash docker/docker.sh recreate app`. A Python source-only edit requires `restart app`, without rebuilding the runtime image. Dependency and frontend build prerequisites are defined by `docker/Dockerfile`; the build context is the repository root.
