# Build RAGFlow Docker Image

This checkout mounts application source into its runtime container. See the [Docker directory](../../docker/README.md) and [operations manual](../operations.html#mount).

```bash
bash docker/docker.sh fetch
bash docker/docker.sh build dev ragflow-local:dev
bash docker/docker.sh build prod ragflow-local:prod
```

Set matching `APP_MODE=dev` / `prod` and `RAGFLOW_IMAGE` in `docker/env/app.env`, then run `bash docker/docker.sh recreate app`. Development uses Vite with mounted source and hot updates; production serves compiled assets. Python edits require `restart app`. See the Docker README for the optional SSH proxy tunnel and verified local resource cache.
