# DataFactory 后端开发指南

适用于 `datafactory/backend/` 中 API、Worker、仓储、连接与发布服务。先读 [总则](../CLAUDE.md)、[技术架构](../product-proposal/TECHNICAL_ARCHITECTURE.md)与[开发计划](../product-proposal/DEVELOPMENT_PLAN.md)。本目录在阶段 1 创建独立 FastAPI 应用及 `datafactory-backend` 包。

## 分层与接口

| 计划模块 | 责任 |
| --- | --- |
| `app/` | 启动检查、REST/SSE、请求 Schema、会话、项目作用域与错误映射 |
| `services/` | 授权、快照、配方、运行、审核、质量、发布与评测的事务边界 |
| `connectors/` | RAGFlow、S3 和结构化记录的 I/O、版本探针、DTO 转换、限流及可诊断错误 |
| `store/` | PostgreSQL、Alembic、对象仓储及不可变产物索引 |
| `worker/` | 领取与续租、检查点与预算、引擎端口注入、重试、取消与回收 |

路由验证并调用拥有业务资料的服务，服务使用仓储与端口；SQL 查询结果映射为内部领域对象。接口挂载在 `/api/factory/v1`。公开 OpenAPI 是前端数据类型的来源。用稳定错误码、请求 ID、可定位字段与 HTTP 状态。游标绑定项目、资源、筛选和排序，创建类操作用幂等键与输入指纹，变更带修订号。

## 身份、知识库和模型连接

- DataFactory 组织 OIDC 与应用会话独立。最小权限检查贯穿项目、来源、连接、资产、模型、作业和产物。角色、资源范围与允许的用途共同授权。
- RAGFlow 连接从受信实例登记开始。后端代表项目建立申请，资源所有者在 RAGFlow 批准。按项目、实例、批准主体与授权范围保留知识库和模型的独立绑定。拒绝通用用户 ID 冒充、任意外部 URL 和跨项目引用。
- mTLS 私钥与组织客户端密钥存密钥系统，元数据库只存引用。按有效授权换取短期访问令牌并校验签发范围；不用原生 RAGFlow 用户密码、浏览器 JWT 或全租户 API Key 代替项目授权。
- 快照读取、检索和模型调用绑定上游资源版本及授权范围。返回用户可读的待审批、失败、过期、撤回、版本变化与能力不匹配。运行中复核，任务涉及的全部来源共同决定出域与导出权限。
- RAGFlow 上游集成端采用独立契约。新增上游实现前先检查实际 RAGFlow 鉴权、资源归属、读写风险、Go/Python 路由和模型调用路径，生产 DataFactory 依赖协议与能力探针。见[连接设计](../product-proposal/TECHNICAL_ARCHITECTURE.md#ragflow-connection)。

## 快照、作业和账目

1. 语料采集以已批准版本和范围为单位，页面带捕获及授权版本。检查分页、状态、片段所属、资产和内容 hash。校验完整后提交快照清单及 READY。
2. 作业和事件同事务入库。领取使用行锁、租约、尝试代数。Worker 每批以当前状态、执行代数、有效租约和来源授权作提交条件。旧执行仍可结算已发调用，不能提交产物。取消、暂停和权限失败分别记录。
3. 调用前按项目、连接、运行的限制核验并预留。保存唯一调用 ID、输入指纹与上游请求 ID。状态未知按核账规则保留预留，查询原订单；提供方状态不明确时暂停继续发送。
4. 产物先写不可变对象并验证哈希，再提交引用。撤回与删除按引用、用途和留存策略处理。下载请求复查用户、对象和数据来源；项目以外的同哈希资产不可访问。
5. 审核以修订记录处理竞态。冻结绑定候选、审核、来源、分组、门禁和适配器版本。审批期间变化需复查，幂等重放返回既有发布。SSE 与列表可复现作业状态。

## 配置、验证与交付

- 运行环境、PostgreSQL、对象桶、凭据、受信 RAGFlow 实例登记彼此隔离。连接至 92 或共用生产计量的 91 实例不得作为写入或模型消费测试目标。配置提供无秘密的示例。
- 默认单测使用合成数据和连接替身。契约测试覆盖两账户、授权和证书不一致、不同库相同 ID、失效资源与分页。隔离持久化层验证事务锁、租约、恢复、幂等与迁移。
- 新增或改动 API 时生成 OpenAPI 与前端类型，验证错误所有者和请求行为。阶段 1 建立 workspace 后，从 `datafactory/` 执行 `uv run --package datafactory-backend pytest backend/tests/unit`，按模块运行 Ruff 与类型检查，真实集成层单独执行。
- 部署前检查 DB/桶目标、Schema、API 健康、Worker 领取、连接能力及主要路径。运维步骤与可回退方式登记到 [files/operations.md](../../files/operations.md)。
