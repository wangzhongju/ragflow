# DataFactory 数据制作核心引擎开发指南

先读 [DataFactory 开发总则](../CLAUDE.md)、[技术架构](../product-proposal/TECHNICAL_ARCHITECTURE.md)与[四类任务契约](../product-proposal/PRODUCT_DESIGN.md#4-四类制作任务)。本目录是独立的 Python 3.13 包 `datafactory-engine` 的计划位置。后端 Worker 通过包接口执行，端口在后端装配。

## 包职责与方向

| 计划模块 | 职责 |
| --- | --- |
| `domain/` | 带类型内容、语料/候选、查询/判定、消息/偏好、任务样本与版本字段 |
| `ports.py` | `CorpusPort`、`RetrievalPort`、`ModelPort`、`CheckpointPort`，以不可变 DTO 与能力信息交互 |
| `recipes/` | 节点注册、输入输出类型、Schema、DAG 编译、成本和能力约束 |
| `pipeline/` | 冻结计划、分层采样、分片批次、检查点、执行结果与失败记录 |
| `tasks/` | Embedding、Reranker、SFT、DPO 的训练样本视图与规则 |
| `quality/`、`adapters/` | 分组、去重、校验、报告、任务训练格式与冻结文件写入 |

核心包只依赖自身类型、计算库和端口。HTTP 客户端、SQLAlchemy、对象存储、RAGFlow 与模型供应商权限和账目由后端处理。模型步骤只有注入的 `ModelPort`，即使是付费召回也走后端的计量边界。

## 配方与执行

- 版本化 JSON Schema 是配方事实源。步骤声明输入、输出、依赖、参数、所需能力、费用上限、输出类型和可诊断的失败码。新步骤必须验证实际种子和 Schema，不拼接业务对象的未声明字段。
- 编译时确认输入引用、循环、节点类型、授权范围、版本、模型能力、预算和模态。运行绑定 `snapshot_id`、固定的 `recipe_revision`、种子、模型与检索指纹以及策略。可编辑参数与运行记录分开。
- 预览和生产共享编译与执行路径。预览 DAG 在选定分组内缩小输入，模型、规则与结果语义一致。限制预览规模和预算。区分低成本诊断与正式批次产物。
- 使用稳定排序和根据运行种子与记录键派生的确定性随机数。用同一分组内可追溯去重与采样处理重试、多批并发和增量记录。外部模型输出保存后复用，重跑不得假设供应商生成字节相同。
- 分批读写并保留进度、已提交范围及不可变对象哈希。把租约、尝试代号、调用 ID 与检查点传给后台端口。阶段提交条件由 Worker 与数据库强制。错误标注可重试、有待核账、资源变更或需要人工判断的类别。
- 将源文本和模型输出视为数据。工具验证使用声明的 Schema 与固定的模拟结果。模板和插件只使用版本化且已注册的能力。

## 任务专用规则

| 任务 | 规则 |
| --- | --- |
| Embedding | Query 可绑定多正例，候选与正例按族、重复和证据排除。难负例保留召回信息与教师指纹。疑似假负例入队，人工确认后可提升正例 |
| Reranker | 原始候选序位与相关性判定分别保存。0 分和未判定分开；只在同一查询组生成有序对，教师分数组与候选对齐 |
| SFT | 验证消息角色、目标轮次、引用与工具 Schema，工具响应关联调用 ID。按适配器检查内容、长度和模态 |
| DPO | 同一上下文 hash 绑定 A/B 两端，保持盲审顺序可追溯。平局、均不合格和未仲裁状态不能进入训练对 |

按库保留检索版本、向量空间和排名。跨库候选用位次融合或批准教师模型重评。来源引用必须在冻结清单内。由编译阶段固定策略，运行中遇到权限、能力或版本变化显式失败。

## 质量、出口与测试

- 按源家族、近重复、同查询/会话及衍生关系分组，再做训练/验证/测试划分。锁定测试保持独立，审核改判可触发相关规则重检。每个阻断带候选记录和规则版本。
- 每个训练适配器声明受支持的任务、模态、Schema 和训练器版本。固定夹具覆盖训练器读回、边界长度、字段对齐和不受支持的样本。导出以冻结数据为输入，固定序列化与排序，用哈希校验再交付。
- 独立单测使用合成语料、固定响应 ModelPort 和内存检查点。覆盖编译拒绝、重放、难负例、跨源评分、数据泄漏、证据失效和导出契约。涉及真实调用放入隔离集成层。
- 阶段 1 建立包和锁文件后，从 `datafactory/` 运行 `uv run --package datafactory-engine pytest engine/tests/unit`。用目录范围 Ruff 和类型检查。上述命令以阶段 1 实现后的项目配置为准。
