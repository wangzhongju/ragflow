## 阶段二：可恢复运行与模型调用台账

2026-11-16，在阶段一代码上继续实施。范围仍为 M0–M2，未连接 91/92，未调用真实模型。

已完成的当前路径：

- 运行创建与配方版本冻结同事务完成，可指定已有版本；版本编号由数据库行锁递增并设唯一约束。运行只读取绑定版本，草稿修改不影响排队或恢复中的任务。运行/预览创建支持持久幂等键。
- `0005_resumable_runs` 增加版本绑定、运行模式/随机种子/批大小、执行代次与租约、预算计数、检查点和 Invocation 台账。升级时将没有冻结版本的旧排队/运行记录明确置为失败，不能拿当前草稿重演旧任务。
- 列按 DAG 分批执行，普通批次 1–64 行；跨批去重在全局阶段执行。完整冻结语料按游标读取，种子 limit 不再截断候选语料；文档 family_id 传给种子行。
- 每个列批次写入带内容哈希的 Parquet 对象，再以 attempt_generation 条件事务提交检查点。对象中保留丢弃行和错误信息；读取验证对象 SHA-256。取消、暂停和重新领取递增代次，旧任务不能提交检查点或数据集。
- Worker 以数据库条件更新领取任务、续租并恢复过期租约。已有成功调用通过 Invocation 重放结果，不重复发送；进程在请求发送后退出时，恢复会标为 billed_unknown 并暂停。当前仍是数据库队列，尚非 Redis Streams。
- `engine/model_client.py` 是所有模型调用入口。文本调用发送前预留调用次数和 Token 上界；Reranker 计入每个文本对重复的查询。明确拒绝释放 Token 预留；成功报告用量后按实际结算；未报告用量保留预留，不能当成零成本或虚构实际费用。
- 超时/连接重置等结果不确定调用保留预留并暂停，自动续跑被拒绝；暂停/取消后的迟到响应仍结算账目，不能写样本。预算控制信号不受列 drop_row/null 策略吞掉。运行预算按配方 `pause | fail` 生效。
- 稠密检索先通过 ModelClient 使用知识库自身模型编码查询，再发送向量，避免 Gateway 文本检索的隐式模型调用漏记。
- 预览成为 1–50 行后台运行，使用同一版本冻结、执行器、检查点、调用台账；结果保存在运行中，不创建 Dataset。运行提供 pause/resume/cancel、指标及 SSE 入口；SSE 定期重新检查项目权限和会话期限。
- 运行页拆到 feature 目录，接入 TanStack Query、生成 API 类型、SSE 与断流刷新、中英文、亮暗主题、显式配方/快照选择、检查点进度、列耗时、调用记录分页及取消确认。共享状态徽标收敛到唯一组件，删除原屏幕中的重复实现。
- 增加 Vitest/MSW、Playwright 本地浏览器桩和 Storybook；升级 Vite/路由/测试工具到实际安装通过的版本。Storybook 文档生成插件的 glob 使用定向覆盖到 14.0.6，消除其 minimatch 传递依赖告警，未使用 force 或忽略 peer 依赖。
