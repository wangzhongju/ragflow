# DataFactory 前端开发指南

适用于 `datafactory/web/`。实施以[产品逐页设计](../product-proposal/PRODUCT_DESIGN.md#7-逐页设计与交互)和[可点击原型](../product-proposal/prototype/index.html)为准，按[开发计划](../product-proposal/DEVELOPMENT_PLAN.md)接通真实功能。交互原型提供版式和演示路径。生产页面以 React、TypeScript、Vite、React Router、TanStack Query 与生成的 OpenAPI 类型实现。

## 页面与视觉

- 使用原型的 26 个页面入口和父级导航关系。共享项目顶栏、侧栏、面包屑、按钮、状态标签、表格、分面筛选、内容检视和表单组件。原型 `styles.css` 的配色、字号、间距与断点是初始视觉 token 的参照。
- 总览首屏显示处置入口和最近运行。数据集使用易扫描列表与证据详情。审核台桌面并列内容、证据和判定，窄屏使用原型的逐条审核卡片。其他长表在容器中滚动。复杂控件保留明确角色标签。
- 相同任务类型导航顺序一致。Embedding 优先展示正/负候选，Reranker 可发现等级与原序，SFT 展示多轮消息及工具证据，DPO 同屏呈现匿名候选与弃权/退回路径。
- 使用简明状态文本、可见焦点、键盘操作、原生表单语义和实际可点击标签。为 1440px、390px、320px 核对布局，检查骨架、空表、验证失败、不可访问、部分完成、权限暂停、快照/模型版本变化。
- 查询、表单与列表筛选状态按用户任务放置。列表的筛选和游标同步到 URL。详情返回能恢复原筛选和焦点。排查溢出时检查从内容到视口的完整父容器约束。

## 关键流程

| 页面编号 | 实施要求 |
| --- | --- |
| 01、02、26 | 独立 OIDC 登录与会话过期回跳。按项目显示计数、可见角色、预算与可查审计 |
| 03–08 | 选择已登记 RAGFlow，创建并复制批准链接，展示待审批、主体确认、库/文档范围、期限、已撤回与恢复。来源分别分组，快照只选择已处理语料版本与对象范围 |
| 09–13 | 配方参数随节点 Schema，明确能力与预算冲突。生成预览和生产，SSE/分页诊断，暂停、继续、取消的按钮状态与服务契约一致 |
| 14–18 | 四类样本浏览、可定位的证据、审核量表、争议和版本。提交时处理并发冲突与失败，保留待处理输入 |
| 19–23 | 支持从问题跳到样本和分组。展示阻断、告警审批、冻结版本和适配器预览，权限改变及时更新下载状态 |
| 24、25 | 比较同一锁定协议，给出回归样本；模型连接独立批准，配置预览与配方选择以授权能力为准 |

## 数据请求与连接安全

- 浏览器只调用 DataFactory API。RAGFlow 批准入口是后端返回的受信链接，从上游页面完成批准，前端观察本方的状态更新。页面表单不收集 RAGFlow 密码、原生 API Key、模型密钥或服务私钥。
- 将后台操作的请求与响应类型集中在生成客户端和领域服务。查询 key 带项目、资源、筛选与版本，按页面授权失效。显示可操作的本地诊断码，隐藏上游原始错误和敏感字段。
- 运行进度通过 SSE 与本地查询状态协调。断线显示最近状态及重连，事件漏页时重新取当前状态。创建、审批、下载的提交中状态及时防重复发送。
- 富文本和附件按 API 返回的类型渲染，HTML 需要净化。证据与下载通过自己的授权端点，禁用由内容提供的任意 URL 附件或脚本。

## 实施与评审

1. 打开原型对应页面和失败路径，对照现有产品页面源码再实现。原型 CSS 与原型功能说明用于实现评审，演示数据用于夹具。生产入口依赖真实项目和后端能力。
2. 先实现组件默认、空、加载、拒绝及窄屏状态，再接入联调。新增跨账户授权交互维持现有布局，验证不同账号的状态独立以及资源撤回后的按钮和证据访问。
3. 阶段 1 建立 Node 工程后，在本目录用锁文件安装，运行 `npm run lint`、`npm run type-check`、`npm run test`、`npm run build`。用 Playwright 核对主流程、键盘和分辨率。前端命令与配置在阶段 1 补齐。
4. 若改动影响布局或任务步骤，同时更新逐页设计、原型和验收路径。对生成类型和 API 契约变化执行差异检查。页面功能达到开发阶段的退出条件才能纳入交付验收。
